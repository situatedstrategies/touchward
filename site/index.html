View the code on GitHub

Built with

  • Expo SDK 57, React Native 0.86, React 19, TypeScript
  • expo-haptics for iOS impacts and React Native Vibration for timed Android patterns
  • expo-notifications for reminders scheduled on the phone
  • expo-linking for the touchward://reward link, so a Shortcut, the Action Button, Back Tap, or a button remapper can fire a tap
  • react-native-svg for the button shapes and the hold timer ring
  • @react-native-async-storage/async-storage for settings and the counter
  • react-native-volume-manager so the volume buttons can count as taps while the app is open

How the code is laid out

App.tsx
Providers and the root screen.
src/types.ts
Settings model, shape list, color swatches, defaults.
src/haptics/
Pattern definitions as buzz and rest pulses, plus the engine that plays them on each platform.
src/components/
The reward button, the SVG timer ring, and the shape paths.
src/notifications/
Reminder schedule math and local notification setup.
src/hardware/
Turns volume button presses into taps.
src/screens/
The home screen and the settings sheet.
src/store/
Persistence and the settings context.
